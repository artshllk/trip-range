# Launch runbook

One ordered sequence from now to an open site. Follow it top to bottom. Each step says **who** acts, **what** they do, **what is checked** after, and **what to do if it fails**. "Claude" means Claude Code working in this repository; "Owner" means you.

Written 26 November 2026. **Launch day: Monday 30 November 2026** (owner decision). Its five-day coverage window, 26–30 November, measures December on every day; a window ending 1 December would measure January on its first collected day, so an origin could fail for calendar reasons. Owner decisions it relies on are recorded in [launch-checklist.md](launch-checklist.md) and [launch sign-offs](../src/config/launch-signoffs.json).

**Ground rules for the whole run**

- Nothing reaches `main` until step 13. Every merge to `main` is a Netlify production deploy: **15 credits**. The launch needs one. Each fix-forward after it costs another 15.
- Production stays behind Netlify team login until step 17. Everything before that can fail without any visitor seeing it.
- The rollback target is the production deploy that is live today: commit `0a84d3a` (Netlify deploy `6b05b563d5386217af89f62e`). Step 12 re-records it on the day.

Keep the shared Upstash database and its variables through any rollback: the older deploy uses the same `RATE_LIMIT_REDIS_REST_*` names. The rollback target predates the per-client limiter, so publishing it also removes the limiter. That is intended for R1 or R2.

Once the domain enrolment is approved, send Claude:

1. A screenshot or the text of the project's site list showing `www.trip-range.com` as approved (no API token, no password).
2. Confirmation that the project ID and marker shown in the Travelpayouts dashboard are the ones set in Netlify production as `TRAVELPAYOUTS_PROJECT_ID` and `TRAVELPAYOUTS_MARKER`. The values themselves can stay out of the chat. Claude confirms both variables exist for production, and reads the marker only from the step 20 URL, which you send anyway.
3. Whether the program terms require specific disclosure wording. If they do, paste the clause: the affiliate disclosure waits on it (owner decision, 26 November).
4. On launch day, step 20: the final Aviasales URL after one real click, and later the dashboard's click count for that day.
